## Tujuan Repositori

Repositori ini dibuat untuk mengumpulkan hasil pengerjaan Tugas 2 mata kuliah Algoritma dan Pemrograman.

Tugas ini bertujuan untuk menerapkan konsep dasar pemrograman Python, seperti penggunaan variabel, input, tipe data, operasi aritmatika, dan output. Selain itu, tugas ini juga melatih penggunaan VS Code, Git, dan GitHub dalam mengelola proyek pemrograman.
